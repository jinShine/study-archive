- 실행 명령: `./gradlew bootRun`
- 만든 클래스: `ProductController`, `ProductService`, `CountService`, `BeanConfig`, `PayService`, `PointService`, `DiMain`, `SignalMain`
- Bean으로 등록된 클래스와 등록 방식
- DI가 일어난 위치
- `@PostConstruct`, `@PreDestroy` 실행 시점
- 종료 시그널과 graceful shutdown 흐름
