# 4회차 실습

커넥션 비교와 ThreadLocal 단독 실험은 [STUDY_GUIDE.md](../STUDY_GUIDE.md)의 **부록. 직접 확인하기**에 정리했습니다. 각 실습의 전체 코드와 결과는 해당 항목을 펼쳐서 봅니다. 실제 수업 프로젝트와 추가 실습 결과는 `spring/` 아래에 기록합니다.

## 예습 때 정한 실습 후보

1. `REQUIRED`에서 내부 예외가 전체 트랜잭션에 미치는 영향 확인
2. `REQUIRES_NEW`로 분리된 트랜잭션의 커밋과 롤백 확인
3. MySQL 세션 두 개로 격리 수준별 조회 결과 비교
4. `EXPLAIN`으로 full scan과 index scan 비교
5. 복합 인덱스의 왼쪽 접두사 규칙 확인
6. `ThreadLocal` 값을 스레드별로 저장하고 `remove()`로 정리
