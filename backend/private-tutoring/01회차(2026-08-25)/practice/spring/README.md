## 상태

## 나중에 Spring과 연결해서 볼 개념

| 1회차 개념 | Spring에서 만나는 위치 |
| --- | --- |
| Client -> Server | `Controller` |
| 비즈니스 로직 | `Service` |
| DB read/write | `Repository`, JPA, JDBC |
| Stateless 서버 | Session, JWT, Redis |
| 모니터링/APM | Actuator, Metrics, Logs |
| Redis Cache | Spring Cache, RedisTemplate |
| Message Queue | Kafka, RabbitMQ, SQS 연동 |
